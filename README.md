# Instagram → Telegram repost bot

Отправляешь боту ссылку на пост Instagram и текст — он скачивает медиа (фото, видео, reels, карусели), публикует в Telegram-канал с твоим текстом, ставит реакцию в канале и (опционально) лайк на оригинал в Instagram.

Пример сообщения боту:

```
https://www.instagram.com/reel/XXXXXXXXXXX/ Мой текст для подписи
```

Ссылка может стоять в любом месте сообщения, всё остальное становится подписью.

Текст можно прислать и **следующим сообщением**: бот ответит «🔗 Ссылка принята, жду текст» и использует следующее сообщение как подпись. Если текст не пришёл за `PENDING_TIMEOUT` секунд (по умолчанию 60) или раньше пришла новая ссылка, пост уходит без подписи.

## Как это работает

- **Вход и скачивание** — всегда через [Instaloader](https://instaloader.github.io/).
- **Лайк в Instagram** (`IG_LIKE=true`) — через `instagrapi`. Он подключается только если лайк включён, при `IG_LIKE=false` не импортируется и не логинится.
- **Пароль нигде не хранится.** Сохраняется только сессия Instaloader (`~/.config/instaloader/session-<логин>`). Если сессии нет или она истекла, пароль запрашивается в терминале.
- При ошибке авторизации во время работы бот перечитывает `.env`, входит заново и один раз повторяет запрос.

## Установка

```bash
# вариант с uv (без ручного окружения)
uv run --with-requirements requirements.txt bot.py

# или обычный pip
pip install -r requirements.txt
python bot.py
```

`instagrapi` нужен только при `IG_LIKE=true`.

## Настройка

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Добавь бота в канал **администратором** с правом «Публикация сообщений».
3. Скопируй `.env.example` в `.env` и заполни:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `CHANNEL_ID` | `@username` канала или `-100…` |
| `ALLOWED_USER_IDS` | твой Telegram ID (через запятую, если несколько); остальных бот игнорирует |
| `IG_USERNAME` | необязательно: логин Instagram. Если пусто — берётся единственная сохранённая сессия или логин спросят в терминале |
| `IG_LIKE` | `true` / `false` — лайк в Instagram |
| `PENDING_TIMEOUT` | сколько секунд ждать текст после ссылки без текста (по умолчанию 60) |
| `DOWNLOAD_TIMEOUT` | потолок на скачивание поста из Instagram, секунды (по умолчанию 180) |
| `REACTION_EMOJI` | реакция бота в канале (по умолчанию 😁); должна быть разрешена в настройках канала |

## Первый вход в Instagram

Запусти бота **в терминале**. Если сессии нет, он спросит логин (если не задан) и пароль, при необходимости код 2FA, и сохранит сессию. Дальше пароль не понадобится, пока сессия жива.

### Если вход по паролю не проходит (challenge, checkpoint, 2FA)

Войди в Instagram в обычном браузере, а потом импортируй сессию оттуда командой Instaloader:

```bash
instaloader --load-cookies firefox
```

Для этого нужен пакет `browser_cookie3`:

```bash
pip install browser_cookie3
# или, не трогая окружение:
uvx --with browser_cookie3 instaloader --load-cookies firefox
```

Команда берёт cookies Instagram из браузера, проверяет вход и сохраняет сессию в `~/.config/instaloader/session-<логин>`, после чего бот подхватит её без запроса пароля. Поддерживаются браузеры: brave, chrome, chromium, edge, firefox, librewolf, opera, opera_gx, safari, vivaldi. В выбранном браузере ты должен быть залогинен в Instagram. Для Safari на macOS терминалу может понадобиться доступ к диску (Full Disk Access).

## Ограничения и заметки

- Обычный бот Telegram не отправляет файлы больше **50 МБ**.
- Подпись в Telegram ограничена 1024 символами; более длинный текст бот отправляет отдельным сообщением после медиа.
- Скачивание и лайки через неофициальные клиенты нарушают правила Instagram и могут привести к ограничениям аккаунта. Лучше использовать отдельный аккаунт и не гонять много постов подряд.
- Instagram хуже относится к IP дата-центров; со своего компьютера или телефона сессии живут дольше.
- Сессия живёт в файле: если бот запускается без терминала (фон, launchd, сервер), а сессия истекла, он ответит ошибкой. Запусти его один раз в терминале и войди заново.

## Логи

Бот пишет в терминал каждый шаг: получение сообщения, запрос метаданных, скачивание файлов (размер и время), отправка в канал, реакция, лайк и итоговое время. Служебные запросы к Telegram (`getUpdates` и т. д.) скрыты. Если Instagram ограничивает запросы и Instaloader засыпает, в логе будет строка «лимит запросов, Instaloader ждёт N с».

## Сон Mac

Бот не мешает сну: он не берёт «assertions» (не использует `caffeinate`) и сам Mac не будит, потому что только опрашивает Telegram исходящими запросами. Пока Mac спит, процесс заморожен, а сообщения ждут в Telegram (до 24 часов). Когда другое приложение вызывает DarkWake или Mac просыпается полностью, бот продолжает работу, обрабатывает накопившееся и в лог пишется строка «💤 Mac спал … с». Пока он что-то делает, Mac сам решает, когда вернуться в сон; бот его не удерживает.

Проверить, что бот ничего не удерживает:

```bash
pmset -g assertions            # в списке не должно быть python
pmset -g log | grep -E "DarkWake|Wake from|Entering Sleep"   # история пробуждений
```

Обработка поста во время короткого DarkWake может не успеть, и тогда она продолжится или завершится ошибкой при следующем пробуждении. Таймауты (`DOWNLOAD_TIMEOUT`, `PENDING_TIMEOUT`) считаются по времени бодрствования, сон в них не входит.

## Частые ошибки

- **`Chat not found`** — неверный `CHANNEL_ID` или бот не добавлен в канал админом. Попробуй `@username` вместо числового ID.
- **Бот «завис» на «Скачиваю…»** — смотри лог: там видно, на каком шаге он остановился. Если Mac засыпал посреди скачивания, соединения обрываются; бот перезапросит их при следующем пробуждении или ответит ошибкой по таймауту.
- **Реакция в телеге не ставится** — выбранный эмодзи не разрешён в канале (Управление каналом → Реакции).
